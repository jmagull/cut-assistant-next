# Spotlight-CAN – Herkunft und Quellen

CAN 1.0.3 Build 50 bindet die gemeinsamen Bibliotheken `SpotlightCan.Core`, `SpotlightCan.Media` und `SpotlightCan.Wpf` aus dem eigenen Spotlight-CAN-Projekt ein. Der fest eingebundene Quellcommit ist **6973b37591e9b581b20b5a6f2117369b6df0f159**, Repository `jmagull/spotlight-can`, Zweig `codex/can-integration`.

Das CAN-Quellarchiv enthält diese vollständigen versionierten Quellen unter `external/spotlight-can`, einschließlich Tests und eigenständigem Host. Ein zusätzliches Spotlight-Quellarchiv enthält denselben Commit. Es sind keine Zugänge oder Git-Metadaten enthalten. Beim Git-Checkout wird weiterhin Zugriff auf das private Repository und `git submodule update --init --recursive` benötigt; das entpackte vollständige Quellpaket benötigt keinen Git-Zugriff auf Spotlight.

Der Spotlight-Quellstand enthält keine eigene LICENSE-Datei. Hier wird dafür keine zusätzliche Lizenz erfunden oder eine öffentliche Verteilungsfreigabe behauptet. Die vorhandene CAN-Lizenz und Drittanbieterhinweise werden unverändert mitgegeben; vor einer späteren öffentlichen Veröffentlichung ist die Lizenzzuordnung der Spotlight-Quellen ausdrücklich zu klären. Dieser Paketsatz bleibt lokal zur Prüfung.

Martins ursprüngliche Idee und AutoIt-Cutfinder werden gewürdigt. Die eigenständige C#-Implementierung übernimmt keine Originaldateien. Die beiliegende Spotlight-README beschreibt die Herkunft und die Grenzen der manuellen visuellen Werbesuche. Keine automatische Werbeerkennung, kein eigener Schnittmotor und kein zweiter Player.
